# Bulgur Royale

Bulgur ve arkadaşlarıyla, osuruk temalı, eğlencelik bir Clash Royale benzeri tarayıcı oyunu. Ticari değildir.

- **Oyna:** GitHub Pages adresi (depo ayarları → Pages).
- **Android:** Releases → `latest` → `BulgurRoyale.apk`. Uygulama oyunu internetten açar, bu yüzden her güncelleme kendiliğinden gelir. İnternet yoksa APK'nın içindeki kopya açılır.

Yerelde çalıştırmak için `index.html` dosyasını tarayıcıda açman yeterli. Müzik dosyaları (`muzik/`) depoda yok. Dosyalar yoksa oyun kendi sentez müziğini çalar.
