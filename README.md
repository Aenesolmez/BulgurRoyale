# Bulgur Royale

Bulgur ve arkadaşlarıyla, osuruk temalı, eğlencelik bir Clash Royale benzeri tarayıcı oyunu. Ticari değildir.

- **Oyna:** GitHub Pages adresi (depo ayarları → Pages).
- **Telefona kurulum (uyarısız):** Chrome ile oyun adresini aç → menü → "Ana ekrana ekle / Uygulamayı yükle".
- **Android APK:** Releases → `latest` → `BulgurRoyale.apk`. Uygulama oyunu internetten açar, bu yüzden her güncelleme kendiliğinden gelir. İnternet yoksa APK'nın içindeki kopya açılır.

Yerelde çalıştırmak için `index.html` dosyasını tarayıcıda açman yeterli. Müzik dosyaları depoda yok. Ayarlar → "Müziklerimi yükle" ile kendi dosyalarını (Menu, Battle, 60 sn, 30 sn, Countdown) telefondan seçebilirsin; dosyalar sadece cihazda kalır. Yüklemezsen oyun kendi sentez müziğini çalar.
